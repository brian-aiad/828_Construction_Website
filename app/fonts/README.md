# Self-hosted fonts

These Latin subset WOFF2 files use the same font families and configured weights as the site's previous `next/font/google` setup. They are distributed locally so production builds do not need to fetch fonts during compilation.

Source packages: `@fontsource-variable/inter@5.3.0`, `@fontsource/space-mono@5.3.0`, and `@fontsource/ibm-plex-mono@5.3.0`.

Each font's SIL Open Font License 1.1 is included beside its files.
